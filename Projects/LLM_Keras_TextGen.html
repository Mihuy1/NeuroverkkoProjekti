Building the Transformer Model¶

In this section, we construct a Transformer-based model for text generation. The model includes the following components:

  1. Positional Encoding: A sinusoidal positional encoding is added to the embedding layer to provide the model with information about the order of tokens in a sequence.
  2. Embedding Layer: Converts token IDs into dense vector representations of a fixed size (embed_dim).
  3. Causal Masking: A causal attention mask is applied to ensure that the model does not attend to future tokens during training.
  4. Transformer Blocks: Multiple layers of multi-head self-attention and feed-forward networks are stacked to capture complex patterns in the data.
  5. Output Layer: A dense layer maps the final representations to the vocabulary size for token prediction.

The model is compiled with the Adam optimizer and sparse categorical cross-entropy loss, and its architecture is summarized for verification.

def get_positional_encoding(max_len, d_model):
    """Create sinusoidal positional encoding."""
    positions = np.arange(max_len)[:, np.newaxis]
    angles = np.arange(d_model)[np.newaxis, :] / d_model
    angles = 1 / (10000**angles)

    pos_encoding = positions * angles
    pos_encoding[:, 0::2] = np.sin(pos_encoding[:, 0::2])
    pos_encoding[:, 1::2] = np.cos(pos_encoding[:, 1::2])

    return pos_encoding

# Define model parameters
embed_dim = 128
num_heads = 2
ff_dim = 256
num_layers = 2

# Create the model
inputs = keras.Input(shape=(seq_length,))
embedding_layer = keras.layers.Embedding(sp.get_piece_size(), embed_dim)(inputs)

# Add positional encoding
pos_encoding = get_positional_encoding(seq_length, embed_dim)
x = embedding_layer + pos_encoding

# Helper function to create causal attention mask
def create_causal_mask(size):
    """Create a causal attention mask to prevent looking at future tokens."""
    mask = 1 - np.triu(np.ones((size, size)), k=1)
    return mask  # Lower triangular matrix

# Transformer blocks
for _ in range(num_layers):
    # Multi-head attention with causal mask
    # Manually create causal mask since use_causal_mask parameter isn't available
    causal_mask = create_causal_mask(seq_length)

    # Apply attention with manual causal mask
    attention_output = keras.layers.MultiHeadAttention(
        num_heads=num_heads,
        key_dim=embed_dim // num_heads
    )(x, x, attention_mask=causal_mask)

    # Add & Norm
    x = keras.layers.LayerNormalization(epsilon=1e-6)(x + attention_output)

    # Feed-forward network
    ffn = keras.Sequential([
        keras.layers.Dense(ff_dim, activation="relu"),
        keras.layers.Dense(embed_dim),
        keras.layers.Dropout(0.1)
    ])
    ffn_output = ffn(x)

    # Add & Norm
    x = keras.layers.LayerNormalization(epsilon=1e-6)(x + ffn_output)

# Final output layer
outputs = keras.layers.Dense(sp.get_piece_size())(x)

# Create model
model = keras.Model(inputs=inputs, outputs=outputs)

# Compile model
model.compile(
    optimizer=keras.optimizers.Adam(learning_rate=3e-4),
    loss=keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    metrics=['accuracy']
)

Training the Transformer Model¶

In this step, the Transformer model is trained using the preprocessed input and target sequences. The training process includes the following configurations:

  • Batch Size: 64
  • Epochs: 20
  • Callbacks:
    • EarlyStopping: Stops training if the validation loss does not improve for 3 consecutive epochs, restoring the best weights.
    • ReduceLROnPlateau: Reduces the learning rate by a factor of 0.5 if the validation loss plateaus for 1 epoch.
    • ModelCheckpoint: Saves the best model during training to the file seitsemanVeljesta_best_model.keras.

The model is trained on 80% of the data, with the remaining 20% used for validation. This ensures that the model's performance is evaluated on unseen data during training.

Text Generation with Transformer Model¶

In this section, we demonstrate the use of the trained Transformer model to generate text based on a given input prompt. The generate_text function takes the following parameters:

  • model: The trained Transformer model.
  • sp: The SentencePiece tokenizer used for encoding and decoding text.
  • start_text: The initial text prompt to begin the generation.
  • length: The number of tokens to generate (default is 100).
  • seq_length: The sequence length used during training (default is 32).

The function generates text by iteratively predicting the next token based on the input sequence and appending it to the generated text. The output is decoded back into human-readable text using the SentencePiece tokenizer.

Below is an example of generated text based on the input prompt "Jukolan". The model produces coherent and contextually relevant text, showcasing its ability to learn patterns and structure from the training data.

In [ ]:
def generate_text(model, sp, start_text, length=100, seq_length=32):
    input_ids = sp.encode_as_ids(start_text)
    generated_ids = input_ids[:]

    for _ in range(length):
        x = generated_ids[-seq_length:]
        if len(x) < seq_length:
            x = [0] * (seq_length - len(x)) + x

        x = np.array(x, dtype=np.int32)[None, :]  # ensure int32 for TensorFlow
        preds = model.predict(x, verbose=0)
        next_id = int(np.argmax(preds[0, -1]))  # make sure it's an int
        generated_ids.append(next_id)

    return sp.decode_ids([int(i) for i in generated_ids])

Summary¶

Short summary¶

A generative text model based on the Finnish novel Seitsemän veljestä by Aleksis Kivi. It includes the following steps:

  • Data Preparation: The text is loaded, preprocessed, and tokenized using SentencePiece with a BPE model.
  • Training Data Creation: Input-output sequences are generated for training and validation.
  • Transformer Model: A Transformer-based architecture is built with positional encoding, multi-head attention, and feed-forward layers.
  • Training: The model is trained with callbacks like early stopping and learning rate reduction.
  • Text Generation: A function is implemented to generate text based on a given prompt using the trained model.
  • Analysis: The generated text is evaluated for coherence, grammar, and creativity.

Analysis of the Generated Text¶

The generated text demonstrates the model's ability to produce coherent and contextually relevant content based on the input prompt. Here are some observations:

  1. Contextual Understanding: The model effectively continues the narrative style and tone of the input text, maintaining the literary and thematic elements of the original work.

  2. Language Structure: The generated text adheres to the grammatical rules of Finnish, showcasing the model's understanding of sentence construction and word usage.

  3. Relevance to Input: The continuation aligns with the context provided, discussing themes of human emotion, conflict, and reasoning, which are central to the original text.

  4. Limitations: While the text is coherent, it may occasionally lack the depth and nuance of human-written literature. The model might also introduce repetitive or less meaningful phrases over longer generations.

  5. Creativity: The text exhibits a degree of creativity, with unique phrases and ideas that reflect the model's ability to generate novel content while still being grounded in the training data.

Overall, the generated text reflects the model's capacity to learn and replicate complex patterns from the training data, making it a valuable tool for creative and literary applications.
